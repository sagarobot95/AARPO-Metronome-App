AARPO Metronome — custom visualiser backgrounds
================================================

Drop an image file in this folder (.png, .jpg, .jpeg, .bmp, .gif or .webp) and
the app will turn it into a colour dot-mosaic behind the beat visualiser. Every
click then sweeps a bright wave-crest outward across the image.

Usage
-----
- Put one or more images in this folder.
- Launch the app. The most recently added image is used automatically.
- Press the  i  key while the app is running to cycle through:
      plain rings  ->  each image in this folder  ->  plain rings ...

Tips
----
- Bold, high-contrast images read best at low resolution.
- The image is centre-cropped to fit; square-ish images lose the least.
- Images here are ignored by git (they stay private to your machine).
